# Geographic data

`world-110m.json` is Natural Earth 1:110m country and land geometry in TopoJSON form, distributed by the Vega datasets project:

- https://github.com/vega/vega-datasets/blob/main/data/world-110m.json
- https://www.naturalearthdata.com/about/terms-of-use/

Natural Earth geographic data is public domain. Country outlines are generalized for overview maps. Story markers describe approximate reporting locations, not surveyed incident coordinates. The publication's renderer and labels are original code; no remote map service, browser tracking, or API key is used.
